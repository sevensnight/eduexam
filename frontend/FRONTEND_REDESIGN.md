# EduExam 前端视觉重构

## 设计方向

面向教师、学生与管理员的日常工作台。采用苹果风格的简洁排版、留白与细节统一，通过现有 Vue 3、Element Plus 和原生 CSS 实现。

改版前主要问题：深色渐变侧栏、阴影较重、统计卡片装饰色不统一、固定宽度登录框、多列表单与考试操作列缺乏移动端适配。

设计参数：布局变化 3/10、动效 2/10、信息密度 4/10。采用固定浅色主题，避免自动切换导致业务页面的状态色与自定义标签失去对比度。

## 视觉规范

- 背景：浅灰 #f5f5f7；内容区：白色；正文：#1d1d1f；次要文字：#6e6e73。
- 主强调色：#0066cc；成功、警告、错误保留语义色；用户创建的标签保留自定义颜色。
- 字体：系统无衬线字体，优先 Apple 系统字体、苹方与微软雅黑；无需下载远程字体。
- 圆角：内容区 16px、控件 9px、标签 6px；弹出层与登录框按照相应容器尺寸设置。
- 卡片采用细边框与间距区分层级；仅交互反馈使用短过渡，并支持减少动态效果偏好。

## 实现结构

- src/style.css：全站设计变量、Element Plus 主题、表单、表格、弹窗、分页及响应式样式。
- src/components/AppNavigation.vue：共用角色导航；桌面侧栏和手机抽屉使用相同来源。
- src/components/AuthShell.vue：登录和注册共用布局。
- src/utils/pageInfo.js：页面标题和描述，不改变原有路由与访问权限。
- src/views/common/Layout.vue：浅色侧栏、页面位置、账号菜单、通知、手机菜单和跳到正文链接。
- src/views/common/Dashboard.vue：欢迎区、统计数据、最新考试、分类分布、常用入口、加载与错误重试状态。
- Login.vue / Register.vue：有明确标签的输入框、自动填充语义、键盘提交、防止重复提交。
- TakeExam.vue：答题进度导航、键盘可操作题号、选项状态、手机纵向布局。
- QuestionList.vue / ExamList.vue / Categories.vue / ExamForm.vue：列表标题、数量、筛选、分类和组卷布局细节。

后端接口、数据库、账号角色和路由地址沿用原项目。宽表格在手机端使用内部横向滚动，操作列不固定覆盖数据区。

## 查看与验证

保持后端和前端运行，刷新 http://localhost:5173 即可；也可使用项目根目录的 start_all.bat。

构建：

```powershell
cd "D:\软件工程与UML\eduexam\frontend"
npm run build
```

浏览器检查脚本依赖 Python Selenium 与 Chrome，仅用于开发验证，运行系统不需要这些工具：

```powershell
python scripts\visual_check.py
```

检查范围：

- 管理员桌面端主要页面、创建题目和创建考试表单。
- 390px 手机视口下的登录、注册、概览、列表、分类、编辑表单、成绩、错题本、统计和个人资料。
- 登录必填校验、教师/学生真实账号登录、角色导航、手机抽屉跳转、题目无匹配搜索与空状态。
- 学生访问管理路由的重定向；浏览器严重错误；文档横向溢出；手机考试固定操作列遮挡。

截图保存在 artifacts/before 和 artifacts/after。检查使用真实登录和查询，不创建、修改或删除业务记录，不实际交卷。答题页样式经过编译检查，未以真实考试提交验证。

原有构建提示仍包含 VueUse 的注释警告及主包体积提示，不影响构建成功。未新增前端运行依赖。
