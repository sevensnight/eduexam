# 统计分析页改版说明

## 设计目标

原页面将分类名称和数量放在一张横跨整个内容区的表格中，名称与数值相距较远，长列表挤占首屏，考试统计位于列表之后。本次将统计分析组织为「题库概览」和「考试分析」两个视图，先呈现关键指标，再展示分布，完整明细通过切换进入。

设计参考：

- [Ant Design 可视化页面规范](https://ant.design/docs/spec/visualization-page/)：按照概览、筛选、明细组织信息，把重要指标放在页面上方。
- [IBM Carbon 数据看板规范](https://v10.carbondesignsystem.com/data-visualization/dashboards/)：明确数据层级，统一布局、间距和颜色，减少妨碍阅读的装饰。

沿用 EduExam 的 Vue 3、Element Plus 和系统无衬线字体，以现有 ECharts 依赖绘制图表。没有引入另一套组件库。视觉方向为浅色、扁平、蓝色强调、低动效；布局变化 3/10，动效 2/10，信息密度 5/10。

## 页面结构与交互

### 题库概览

- 顶部展示已分类题目、有题分类、单类平均题量、当前账号可见考试四项指标。
- 横向条形图默认展示题量前 8 个分类，数值直接标注在条形末端；悬停可查看数量和真实占比。
- 构成图保留前 5 个分类，其余合并为「其他 N 个分类」，合并前后题量总数一致。
- 「明细」视图展示所有分类，支持名称搜索和每页 8 行的分页；搜索只过滤列表，占比仍以完整题库的已分类题量为基数。
- 教师看到自己创建的题目；管理员看到接口允许查看的全部题库。

### 考试分析

- 支持考试搜索、原有考试列表分页以及跳转已有的详细报告页；默认优先选择状态为已结束的考试。
- 展示统计人数、平均分、及格率、良好率、优秀率、最高分。
- 成绩柱状图支持切换到人数和占比明细；分数区间沿用后端的满分百分比区间，不将其误写为绝对分数。
- 教师和管理员可以查看平均得分率最低的 5 个知识点；低于 60% 时采用橙色提示。
- 试卷分类分布复用题库分布组件。
- 学生仅显示获准访问的考试统计；成绩未公开或统计尚未开放时，展示说明，不显示成绩数据或教师分析模块。

## 数据口径

- 已分类题量：分类统计接口返回数量之和，不冒充全部题库数量。
- 有题分类：题量大于零的分类数，不包含空分类。
- 分类占比：该分类题量 / 全部已分类题量，不使用「该分类题量 / 最大分类题量」作为占比。
- 单类平均题量：已分类题量 / 有题分类数。
- 成绩统计沿用后端的「每位学生最高已批改成绩」规则。
- 没有已批改成绩时，人数为 0，平均分和比例显示 `-`，并显示等待批改说明。
- 及格率遵循考试设置的及格线；良好率和优秀率分别遵循后端的满分 75%、90% 阈值。
- 所有正式页面数据均来自现有接口；没有新增数据库表、修改 SQL 或写入示例业务记录。

## 实现文件

- `src/views/common/Stats.vue`：视图切换、指标、考试选择、成绩分布、知识点分析和加载状态。
- `src/components/analytics/CategoryDistribution.vue`：分类排名、构成图、明细搜索和分页。
- `src/components/analytics/AnalyticsChart.vue`：按需注册条形图与饼图，使用 SVG 渲染；容器尺寸变化时自适应，卸载时清理图表和观察器。
- `src/utils/analytics.js`：分类排序、分组、占比、数字格式化和安全的图表提示框配置。
- `src/api/index.js`：统计接口及考试列表支持可选请求配置，使页面能够自行展示加载失败提示。既有调用方式兼容。

请求序号保护考试切换和列表分页，较早返回的请求不会覆盖后一次选择。分类统计、考试列表、考试统计和知识点分析分别处理失败状态，失败不会被显示为成功的零数据。

## 悬停显示问题修复

### 柱条及数值被遮挡

原先把 `axisPointer.shadowStyle.color` 设置为不透明的浅色，而当前 ECharts 的轴指示器默认 `z` 为 50，柱条的默认层级更低。浏览器实际 SVG 显示：柱条仍在，但高亮背景最后绘制，覆盖了柱条和末端数字。

分类图和成绩图统一将轴指示器设为 `z: 0`，并使用 5% 透明度的浅蓝色，保证「背景 → 柱条/数值 → 提示框」的绘制顺序。保留原有高亮效果和数量、占比，不改动数据。

### 环形图提示框与中心总数叠字

中心总数是独立的 HTML 绝对定位层，原来的提示框在 SVG 内绘制，不能越过后绘制的中心总数。因此单纯增加 ECharts 内的 `z` 无法修复两个 DOM 图层之间的遮挡。

环形图容器建立局部堆叠上下文：总数在第 0 层，图表及提示框在第 1 层。提示框使用完整白底，移出后中心总数正常显示，不用全局超高层级影响导航或下拉框。

### 连续移动鼠标时提示框不更新

逐扇区悬停还复现了原 SVG 富文本提示框挡住下一扇区的鼠标命中。统计图统一使用非交互式 HTML 提示框，明确 `enterable: false`，使鼠标事件穿透到柱条和扇区；关闭跟随过渡以避免拖尾，限定宽度并允许长名称换行。图形本身仍使用 SVG，没有新增图表依赖。

HTML 提示框通过 `formatChartTooltip` 转义 `& < > " '` 后再拼接受控的换行标签；分类名或分数区间只作为文本展示，不会被解释为 HTML。对应单元测试包含带标签、引号和事件属性的输入。

悬停检查截图以 `hover-*` 命名，位于忽略跟踪的 `artifacts/stats-redesign/`。本次只调整前端展示与回归脚本，不更改 SQL、业务数据或统计口径。
